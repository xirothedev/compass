# Rule-based aspiration suggestions in v1, no ML yet

V1 uses a `user_score ± margin` rule against 2023-2025 cutoff scores (+2 pts Safe / ±1 pt Match / -1 to -3 pts Reach) with a confidence interval from quota fluctuation. Transparent enough that candidates understand why each suggestion was made. ML waits for v2, once we have real admission outcomes + a dense enough review base.

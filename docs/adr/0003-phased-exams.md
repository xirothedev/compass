# V1 full rank for THPTQG only, other exams are manual entry

Complete public bulk data only exists for THPTQG (GitHub/Kaggle 2016-2025). DGNL-HCM/HN, TSA, and transcript-based admission have no bulk data for trustworthy rank computation. So v1 computes ranks for THPTQG only; other exams get manual score entry + manual cutoff lookup, with no rank displayed to avoid misleading numbers.

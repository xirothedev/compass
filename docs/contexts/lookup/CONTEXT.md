# Lookup

Exam score rank lookup: Thí sinh enters scores manually by Tổ hợp xét tuyển, and the system compares them against the ingested Phổ điểm to return rank + percentile.

## Language

**Thí sinh**:
A person taking the exam who needs Thứ hạng lookup and Nguyện vọng suggestions.
_Avoid_: học sinh, user, candidate

**SBD**:
Exam registration number, the unique identifier of a Thí sinh within one Kỳ thi in one year. The first 2 digits are the province code.
_Avoid_: ID thí sinh, mã dự thi

**Kỳ thi**:
One standardized exam session (THPTQG, DGNL-HCM, DGNL-HN/HSA, DGTD-TSA, HocBa).
_Avoid_: kỳ kiểm tra, exam type

**Chương trình**:
The general-education curriculum track of a Thí sinh (CT2018 mainstream / CT2006 for independent candidates). Since 2025, Phổ điểm and Thứ hạng are computed separately per Chương trình.
_Avoid_: chương trình học, curriculum

**Tổ hợp xét tuyển**:
The set of subjects used for admission (A00: Math-Physics-Chemistry, D01: Math-Literature-English, ...). Each Kỳ thi has its own grading scale.
_Avoid_: khối thi, combo môn

**Phổ điểm**:
The distribution of Thí sinh counts by score level for one subject or Tổ hợp xét tuyển in one year.
_Avoid_: distribution, biểu đồ điểm

**Thứ hạng**:
The relative position of one score level within the Phổ điểm. Shown as an absolute rank (e.g. 12,345/1,070,000) and a percentile (top X%).
_Avoid_: ranking, xếp hạng, rank điểm

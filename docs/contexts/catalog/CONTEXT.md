# Catalog

Admissions catalog: Trường, Ngành, and Điểm chuẩn across years per Phương thức xét tuyển. Seed sources are public datasets + the VietnamNet crawler; tuition/quota entered manually from each school's admissions plan.

## Language

**Trường**:
A higher-education institution with the Ministry's standard school code.
_Avoid_: đại học, university, cơ sở đào tạo

**Ngành**:
A degree program under one Trường, with a major code + admission subject combinations + quota.
_Avoid_: khoa, major, chuyên ngành

**Điểm chuẩn**:
The lowest admitted score of one Ngành in one year under one admission method.
_Avoid_: điểm sàn, cutoff, điểm đậu

**Phương thức xét tuyển**:
How admission happens (THPTQG scores, DGNL, HocBa, direct admission, ...).
_Avoid_: hình thức xét tuyển, method

# Guidance

Aspiration placement: Định hướng collects Thí sinh information, the system suggests Nguyện vọng in 3 safety buckets, with school Reviews from students.

## Language

**Nguyện vọng**:
One Trường + Ngành choice that a Thí sinh registers for admission, ordered by priority.
_Avoid_: NV, wish, lựa chọn

**Định hướng**:
A 4-step intake flow (scores + combination, field group, region + budget, risk appetite) that feeds Nguyện vọng suggestions.
_Avoid_: khảo sát đầu vào, quiz, setup, onboarding

**Gợi ý nguyện vọng**:
A Nguyện vọng list bucketed into 3 groups: Safe / Match / Reach.
_Avoid_: recommend, tư vấn, dự đoán đậu

**Review**:
A rating of one Trường by current/former students against fixed criteria + comments.
_Avoid_: bình luận, rating, feedback
